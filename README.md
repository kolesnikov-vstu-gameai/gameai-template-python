## Структура репозитория

```
src/gameai/        исходный код (пакет)
experiments/       скрипты экспериментов (каждый пишет метрики в results/)
results/           метрики (json/csv) и графики — коммитятся, это доказательство
notebooks/         черновые исследования
tests/             pytest
docs/report/       разделы пояснительной записки (00–05)
docs/adr/          архитектурные решения
docs/defense/      презентация к защите
```

## Этапы работы

Работа ведётся по 6 этапам жизненного цикла (см. Issues → Milestones, шаблоны issue):
1. Постановка задачи (нед. 1–2) · 2. Анализ (3–4) · 3. Прототип (5–10) · 4. Интеграция и тесты (11–13) · 5. Отчёт (14–15) · 6. Защита (16–17)

Создать вехи и метки автоматически: `bash scripts/setup_github.sh`

## Воспроизводимость

- Все эксперименты фиксируют `seed` и пишут результат в `results/<experiment>/<timestamp>.json`.
- Датасеты не коммитятся: положите их в `data/raw/` и опишите источник в `data/README.md`.
